## 🌊 ABYSS

ABYSS is a frontend project being developed for the HackOcean 2026 hackathon. The goal is to create a modern and immersive web experience for a fictional deep-sea exploration company.

## 🚧 Current Status

The project has been initialized with React and Vite. Development is currently in progress.

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- CSS
